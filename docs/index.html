Add AnImestream Extensions

Adds the community provider repository to AnImestream so its anime and manga sources appear in the app.

Open in AnImestream

AnImestream must be installed on this device. If nothing happens, use the manual option below.

Manual install

  1. Open AnImestream.
  2. Go to Settings → Providers → Add repository.
  3. Paste the URL and confirm.
